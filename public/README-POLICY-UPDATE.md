# SAIXORA terms & privacy — replacement files

Updated: 21 September 2026

## Install
Copy `terms.html` and `privacy.html` into the same directory as your current `main.html`, replacing only the existing two files. They reuse the existing `main.css`, `site.js`, logo assets, navbar, footer, and mobile navigation. No other animation, server or download code is changed.

If using the original packaged layout, these files belong in `saixora-secure-release/public/`. If you intentionally run a local root-folder layout, replace them alongside your other HTML pages.

## Must verify before an actual public/paid launch
1. Confirm and show the real legal contracting name and a reliable business contact/complaints channel. SAIXORA is currently described as a student-founded initiative, not a registered company. Involve a parent/guardian and qualified Indian legal professional with contracts and school data processing.
2. Contact form in this package still has a blank `config.js` endpoint; the text explicitly discloses that it does not send messages yet. Do not tell visitors that submissions reach your inbox until you implement and test delivery. Once enabled, update the privacy notice with your real provider, retention, and request contact.
3. Confirm actual production website host, network logging, analytics, Google Fonts, security controls, and data retention. Set a documented retention schedule; do not claim that absent logging or tracking has been verified.
4. Keep `private/downloads/`, the server, source code, and secrets outside the served public directory; use HTTPS, private production secrets, and a freshly rotated PIN. A shared PIN is not per-school authentication.
5. Create a **separate** school data processing/privacy and software license agreement BEFORE deploying Secure Nova (classroom monitoring, staff/student notices, school role, access, retention, breach handling, third-party services, device administration, source-code rights, maintenance fees). These two website pages do not cover the apps.
6. Verify third-party trademarks/images and the applicable Indian requirements, including commencement dates of the DPDP Act and Rules. Have qualified counsel review before relying on these drafts as legal terms.
